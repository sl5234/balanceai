# Product value proposition

**Decision:** BalanceAI's core value proposition is three pillars — (1) easy expense logging, (2) easy expense management/categorization, (3) easy intent-aware analysis (natural-language queries against your own data). FAQ is not a fourth pillar; it collapses into (3) as the same Q&A interaction pattern, differing only in whether the backend needs the user's own data or general knowledge.

**Why:** 5-whys traced the original framing (FAQ / bookkeeping / analyze expenses) to its root — users log expenses because future interests are unpredictable (can't know today what you'll want to ask tomorrow), and they want objective understanding because it often serves high-stakes decisions (e.g. "can I quit my job and live off savings"). Both roots point at flexible capture + flexible querying, not a fixed feature list copied from convention.

**Retracted along the way:** a proactive goal/budget-alerts layer was floated as the "true" v1 differentiator, but doesn't match the actual reasoning (which is about *ad-hoc, unpredictable* queries, not ongoing target-tracking) — dropped.
